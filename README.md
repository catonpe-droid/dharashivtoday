# Dharashiv Today — independent newsroom

Demo: https://catonpe-droid.github.io/dharashivtoday/
Admin: https://catonpe-droid.github.io/dharashivtoday/admin/

Enable GitHub Pages using GitHub Actions in Settings > Pages. The build generates story pages, metadata and sitemap. For publishing use a fine-grained token with Contents read/write on this repository only. Never commit credentials. A separate Cloudflare publisher is optional and not configured. Future custom domains are supported by the build's Pages base URL.
